# 🔋 EV Demand Forecasting App

A Streamlit web application to forecast Electric Vehicle (EV) adoption trends across counties.

## 🧠 Features
- Select a county and view 3-year EV adoption forecasts
- Interactive graphs and charts
- Compare trends across up to 3 counties

## 🚀 How to Deploy on Streamlit Cloud
1. Upload all files in this repo to a GitHub repository
2. Go to [Streamlit Cloud](https://streamlit.io/cloud) and click "New App"
3. Connect your GitHub, select the repo, and set `app.py` as the main file
4. Click Deploy!

## 🗂️ Files
- `app.py`: Main Streamlit app
- `requirements.txt`: Python dependencies
- `forecasting_ev_model.pkl`: Trained ML model (you must upload your own)
- `preprocessed_ev_data.csv`: Cleaned data for the app (you must upload your own)
